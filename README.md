# Rebs Scorpion 1.3 Fix

Compatibility override for **BLACKOUTS / vg7_scorpion** + 80s retro / biker paint pack.

- DayZ **1.29** ready, safe for **1.30**
- Override only – original mod untouched
- **No OG classname collisions** – every paint uses `vg7_scorpion_Rebs_*`
